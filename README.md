# GitHub Themes for IntelliJ

[![Version](https://img.shields.io/jetbrains/plugin/v/20810-github-themes.svg)](https://plugins.jetbrains.com/plugin/20810-github-themes)
[![Downloads](https://img.shields.io/jetbrains/plugin/d/20810-github-themes.svg)](https://plugins.jetbrains.com/plugin/20810-github-themes)

GitHub-inspired UI themes and editor color schemes for JetBrains IDEs: IntelliJ IDEA, PhpStorm, WebStorm, PyCharm, GoLand, Rider and more.

This repository holds the **license** and the **issue tracker** for the plugin. The plugin's source code is not public.

---

## Themes

| Dark | Light |
|---|---|
| Github - Dark Default | Github - Light Default |
| Github - Dark Dimmed | Github - Light |
| Github - Dark | Github - Colorblind |
| Github - Dark Colorblind | Github - Light Tritanopia |
| Github - Dark Tritanopia | Github - Light High Contrast |
| Github - Dark High Contrast | |

Each theme comes with a matching editor color scheme, which is applied automatically.

- **Colorblind** themes are for red–green color blindness: success is blue and errors are orange.
- **Tritanopia** themes are for blue–yellow color blindness: success is blue and errors stay red.
- **High Contrast** themes increase the contrast of text, borders and highlights for low vision.

## Installation

- **From the IDE:**
  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>Marketplace</kbd> > search for **"GitHub Themes"** > <kbd>Install</kbd>

- **Manually:**
  Download the latest version from the [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/20810-github-themes/versions), then use
  <kbd>Settings/Preferences</kbd> > <kbd>Plugins</kbd> > <kbd>⚙️</kbd> > <kbd>Install plugin from disk...</kbd>

To switch themes, go to <kbd>Settings/Preferences</kbd> > <kbd>Appearance & Behavior</kbd> > <kbd>Appearance</kbd> > <kbd>Theme</kbd>.

## Reporting an issue

Found a color that looks wrong, a hard-to-read element, or a compatibility problem?
[Open an issue](../../issues/new/choose) and include:

- the theme name (for example *Github - Dark Default*),
- your IDE and version (<kbd>Help</kbd> > <kbd>About</kbd>),
- the plugin version,
- a screenshot of the problem.

Theme and color requests are welcome too.
